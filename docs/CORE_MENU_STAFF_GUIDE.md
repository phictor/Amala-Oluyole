# Core Menu Staff Guide

The customer menu now contains only the current core restaurant list: **Swallow, Main Dish, Sides, Soup, and Protein**. Staff manage it in the web portal: sign in as an administrator, open **Menu**, choose an item, edit the price if required, and use the availability control when stock runs out.

| Category | Customer price format | Staff action |
|---|---|---|
| Swallow | Per wrap | Keep the listed price per wrap. |
| Main Dish and Sides | Per portion | Keep the listed price per portion. |
| Soup and Protein | Per portion | Keep the listed price per portion. |

## Pending soup prices

**Gbegiri, Ewedu, and Okro are intentionally unavailable.** The restaurant did not provide their prices. They do not appear for purchase, including in **Build Your Swallow**, so no customer can accidentally place a ₦0 order.

When the manager confirms a price, open **Menu**, select the soup, enter the confirmed amount, then set it to available. Build Your Swallow reads these options from the live menu, so the revised amount will be used everywhere without a code change.

## Photo rule

Only show an image when it visually represents the named item. Upload or replace an image from the menu-management screen; leave the image empty when the restaurant has not confirmed a match. The customer card will remain compact and clear without an image.
