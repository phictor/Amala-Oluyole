# Oluyole Kitchen Web Portal

## Purpose

The kitchen team uses a **dedicated staff-only browser portal**. It is separate from the customer menu and does not show finance or rider screens to kitchen users.

Open this address on the kitchen computer or tablet:

`https://amalapp-pz8p5xvu.manus.space/staff/kitchen`

Bookmark the page. Kitchen staff sign in with their assigned work account; the system opens the protected **Oluyole Kitchen** workspace automatically.

## Access and roles

| Account role | Access |
|---|---|
| Kitchen | Orders, inventory, and kitchen report for Oluyole Town Planning |
| Admin / Manager | Full kitchen access plus finance, menu, riders, and staff management |
| Customer / Rider | No kitchen access |

The primary Admin / Manager email is **amalaoluyole@gmail.com**. On its first verified sign-in, the system assigns the admin role automatically.

## Daily kitchen workflow

1. Open the portal before service and sign in.
2. Use **Orders** to move each order through: **New Order → In Progress → Ready**.
3. Read the dish list and special instructions before preparing an order.
4. Use **Inventory** to record restocks and ingredient usage. Every stock movement records the signed-in staff member automatically.
5. Use **Report** to review the current month’s order volume, revenue, and most-ordered meals.

## Important menu rule

For Amala meals, **Gbegiri is included by default**. **Ewedu is optional** and selected only for customers who prefer it. Neither accompaniment is sold as a standalone soup.

## Manager actions

The manager updates prices and availability from the **Menu** screen in the Admin / Manager portal. Mark an item unavailable immediately when it runs out; it disappears from customer ordering until reactivated.
