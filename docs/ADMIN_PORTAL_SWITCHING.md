# Admin Portal Switching — Step-by-Step

This is a quick visual reference for how the admin navigates between all portals.

---

## The ☰ Hamburger Button

Every admin screen has a **dark blue circular button** in the **bottom-right corner** with three horizontal lines (☰). This is the Admin Menu trigger.

```
┌─────────────────────────────────┐
│  Finance Dashboard              │
│                                 │
│  ₦0 Total Revenue               │
│  0 Orders Today                 │
│                                 │
│  [Dine-In Revenue Section]      │
│                                 │
│  [7-Day Bar Chart]              │
│                                 │
│                          [☰ 3]  │  ← tap this
└─────────────────────────────────┘
```

The number badge (e.g. `3`) shows pending + kitchen orders that need attention.

---

## The Slide-Up Menu

Tapping ☰ slides up a panel from the bottom:

```
┌─────────────────────────────────┐
│  Admin Menu              [✕]   │
├─────────────────────────────────┤
│  💳  Finance            ◀ active│
│  📋  Orders          [3 badge] │
│  🍽️  Kitchen         [3 badge] │
│  🛵  Riders                    │
│  🛍️  Menu                      │
│  👥  Staff                     │
│  ⚙️  Settings                  │
└─────────────────────────────────┘
```

- The **active section** has a blue left border indicator.
- **Order count badges** appear on Orders and Kitchen when there are pending items.
- Tap any row to navigate. Tap ✕ or tap outside to close without navigating.

---

## Switching to Customer View

1. Open the Admin Menu (☰).
2. Tap **⚙️ Settings**.
3. Scroll to the bottom of Settings.
4. Tap **Preview Customer App**.

You are now in the customer home screen. A floating **⚙️ Admin** pill appears at the bottom right of every customer screen.

---

## Returning from Customer View

Tap the **⚙️ Admin** pill (bottom right). A sheet appears:

```
┌─────────────────────────────────┐
│  Switch Portal                  │
├─────────────────────────────────┤
│  💳  Finance & Operations       │
│  🍽️  Kitchen Portal             │
│  🛵  Rider Portal               │
│  👤  Customer View              │
└─────────────────────────────────┘
```

Tap **Finance & Operations** to return to the admin portal. Tap **Kitchen Portal** or **Rider Portal** to preview those portals as well.

---

## Summary Table

| From | To | How |
|---|---|---|
| Any admin screen | Another admin section | Tap ☰ → select section |
| Admin portal | Customer view | ☰ → Settings → Preview Customer App |
| Customer view | Admin portal | Tap ⚙️ Admin pill → Finance & Operations |
| Customer view | Kitchen portal | Tap ⚙️ Admin pill → Kitchen Portal |
| Customer view | Rider portal | Tap ⚙️ Admin pill → Rider Portal |

No sign-out is ever required to switch between portals.
